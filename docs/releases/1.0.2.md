## 1.0.2

Minecraft 1.7.10 / GTNH，支持 **GTNH 2.9.0-RC1 及以上版本**。

### 修复

- 太空电梯的加工状态识别。太空电梯主方块本身不跑配方，真正加工的是结构内部的模块主机（一般用太空组装模块）。这两类都继承 TecTech 的 `TTMultiblockBase`，结构检查走 `checkMachine_TT`，不经过 GT 常规多方块用的 `checkStructure`；ECO 的加工监控只挂在前者上，所以模块的输入仓/总线从来没被登记到「主机—输入」关系里，监控只会显示「未找到主机」，读不到加工进度与实际并行。
- 修复后同时挂接 `checkMachine_TT`，覆盖所有 TecTech 型多方块：太空电梯、太空组装 / 采矿 / 抽液 / 研究模块，以及 TecTech 自己的多方块。

### 预期表现

- 太空组装模块在跑配方时，ECO 合成监控 / 终端应显示模块名字、加工进度、剩余时间与实际并行，而不是「未找到主机」。
- 未实机验证：本版只做了编译与静态校验，需实机确认上面的表现。

### 安装

1. 删除旧版 `neoecoae-*.jar`。
2. 放入 `neoecoae-1.0.2.jar`（只保留一个）。
3. 启动后日志显示 `Neo ECO AE Extension 1.0.2`。
