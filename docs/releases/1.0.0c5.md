## 1.0.0c5（本地测试版）

Minecraft 1.7.10 / GTNH，支持 **GTNH 2.9.0-RC1 及以上版本**。

### 新增

- 合成状态页双进度显示：
  - **格子底部 2px 细条 = 全局进度**：这个产物在本单里已完成的比例。
  - **整格填充 = 当前机器周期进度**：和原来一样，每轮配方循环一次。
  - 两者同时可见，鼠标悬浮提示里也会显示「全局进度 xx%」和一条全局进度条。
- 全局进度的分母在**下单时**按计划里每个产物的总产量记录（例如这一单要出 100 万铁锭、50 万铜锭，就分别是 100% 的基准），不会随机器批次循环重置。
  - 主产物按**已交付量**计算；
  - 其它产物（中间材料）按**已发配量**计算（中间产物没有独立的交付台账）。

### 说明

- 纯显示层改动：不参与发配与结算，不改配方/方块/ID；任务进度数据随任务存档，旧存档读不到时回落到原来的单进度条。

### 安装

1. 删除旧版 `neoecoae-*.jar`。
2. 放入 `neoecoae-1.0.0c5.jar`（只保留一个）。
3. 启动后日志显示 `Neo ECO AE Extension 1.0.0c5`。
